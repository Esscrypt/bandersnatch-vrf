# Security

This package is part of [Peanut Butter AND JAM (PBNJ)](https://github.com/Esscrypt/peanutbutterandjam).

**Do not open a public GitHub issue for security vulnerabilities.**

Please report security-sensitive issues as described in the **repository root**:

**[SECURITY.md](../../SECURITY.md)** (in the monorepo root)

In short: report via email to the maintainers (see [peanutbutterandjam.xyz](https://www.peanutbutterandjam.xyz/get-in-touch)) or via [GitHub Security Advisories](https://github.com/Esscrypt/peanutbutterandjam/security/advisories/new).
